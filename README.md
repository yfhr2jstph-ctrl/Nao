# ポケカ コレクション 🃏

ポケモンカードの**コレクション管理・検索**アプリ。スマホでホーム画面に追加して使える PWA です。

- 🔍 **カード名で検索**（日本語）— [TCGdex](https://tcgdex.dev/) の多言語カードDBから取得
- ➕ **所持枚数を登録** — 「＋／−」で枚数を増減
- 🗂️ **マイコレクション** — 名前で絞り込み、種類数・合計枚数を表示
- 📦 **収納ボックス管理** — 各カードに物理ボックス名を設定し、ボックス別に絞り込み・どの箱に入れたか一目で確認
- 💾 **端末内に保存** — IndexedDB に保存。サーバー・ログイン不要
- 📱 **PWA** — ホーム画面に追加、オフラインでもコレクション閲覧・カード画像はキャッシュ
- 🔁 **書出／読込** — JSON でバックアップ（機種変更時の移行用）
- 🛠️ **デッキ作成** — 複数デッキを保存、公式ルール検証（60枚／同名4枚まで／たねポケモン）、所持と照合して**足りないカード**を表示

## 技術構成

| 項目 | 採用 |
| --- | --- |
| フロント | Vite + React + TypeScript |
| 保存 | Dexie（IndexedDB） |
| カードデータ | TCGdex REST API（`ja` 日本語） |
| PWA | vite-plugin-pwa（Workbox） |

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド結果をプレビュー
npm run typecheck  # 型チェックのみ
```

> **データ取得について**：カード情報は端末のブラウザから直接 `api.tcgdex.net` を呼びます。
> ネットワーク制限のある環境（CI のサンドボックス等）では取得できないことがありますが、
> 実機・通常のブラウザでは問題なく動作します。

## デプロイ（GitHub Pages）

`.github/workflows/deploy.yml` で自動デプロイします。

1. リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定
2. `main`（または開発ブランチ）に push すると自動ビルド＆公開
3. 公開URL: `https://<ユーザー名>.github.io/Nao/`

プロジェクトサイトはサブパス配信のため、ビルド時に `BASE_PATH=/Nao/`（リポジトリ名と一致）を
渡しています（ワークフロー内で設定済み）。独自ドメインやユーザーサイトの場合は `BASE_PATH` を調整してください。

## データ構造

所持カード1件（IndexedDB `items` テーブル）:

```ts
{
  id: string;        // TCGdex のカードID（主キー）
  name: string;      // カード名
  localId: string;   // セット内の番号
  setName: string;   // セット名
  image?: string;    // 画像ベースURL（/high.webp 等を付けて使用）
  rarity?: string;   // レアリティ
  quantity: number;  // 所持枚数
  box?: string;      // 収納している物理ボックス名（未設定は省略）
  addedAt: number;   // 追加日時
}
```

## 収納ボックス

実物のカードを「どの箱・バインダーにしまったか」を記録できます（すべて端末内）。

- **設定**：カード詳細の「収納ボックス」欄にボックス名を入力（既存の名前は候補から選択可、新規入力もOK）。所持カードのみ対象。
- **絞り込み**：コレクション上部のチップで `すべて／各ボックス（種類数つき）／未設定` を切り替え。
- **一覧表示**：各カードに 📦 ボックス名タグを表示。
- ボックス名は所持データに含まれるため、JSON の書出／読込でそのまま引き継がれます。

## デッキ機能

「デッキ」タブから複数のデッキを作成・保存できます（すべて端末内）。

- **カード追加**：デッキ編集中に「カードを追加」→ 検索 → カード詳細の「〈デッキ名〉に入れる」で採用枚数を増減
- **公式ルール検証**：合計60枚ちょうど／同名カード4枚まで（基本エネルギーは無制限）／たねポケモン1体以上 をチェックリスト表示
- **所持と照合**：各カードを「所持◯／必要◯」で表示し、不足分（買い足しが必要な枚数）を集計

> たねポケモン・基本エネルギーの判定は TCGdex の `category` / `stage` を使います。
> 言語によって表記が異なる場合に備えて緩めに判定し、情報が無いときは「判定不可」と表示します。
> 実データで表記が違っていれば `src/deck/validate.ts` の判定を調整してください。
